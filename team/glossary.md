# AETHERIS — Glossary

## Begriffe und Definitionen

### AETHERIS (Das Projekt)
Ein großes Unreal Engine 5.8-Projekt mit komplexer Simulation, KI-gesteuerten autonomen Individuen, procedurally generated Worldbuilding und multi-agent orchestriertem Development.

### Autonome Individuen
KI-gesteuerte Entitäten im Spiel, die eigenständiges Verhalten zeigen, Entscheidungen treffen und mit der Umgebung sowie anderen Individuen interagieren.

### World Generation
Prozedurale Generierung der Spielwelt basierend auf Regeln, Biome, Ökosysteme und geografischen Mustern.

### Flock / Swarm Behavior
Kollektives Verhalten autonomer Individuen nach Schwarm-Regeln (Separation, Alignment, Cohesion).

### Game Design Document (GDD)
Das zentrale Dokument, das alle Spielmechaniken, Regeln, Inhalte und das Spielerlebnis beschreibt.

### Epic
Eine große Feature-Gruppe, die in mehrere Tasks zerlegt wird.

### Sprint
Ein 2-Wochen-Zyklus mit definierten Zielen und deliverables.

### Spike
Eine Zeit-boxierte Forschungsphase, um technische Machbarkeit zu validieren, bevor ein Feature gebaut wird.

### Agent (im Team)
Ein spezialisierter Hermes-Agent mit eigener SOUL.md, eigenen Skills und klar definierten Verantwortlichkeiten.

### Lead / Producer
Die koordinierende Instanz (ich). Setzt Prioritäten, managt Abhängigkeiten, beschleunigt Entscheidungen.

### Game Designer
Definiert Spielmechaniken, Regeln, Inhalte und das Spielerlebnis.

### Systems Architect
Entwickelt die technische Architektur, wählt Patterns, definiert Datenstrukturen und Integrationspunkte.

### Gameplay Programmer
Implementiert die Spielmechaniken: Movement, Combat, Interaction, UI-Systeme.

### AI Programmer
Implementiert KI-Verhalten, Navigation, Decision-Making, Flock/Swarm-Systeme.

### Tools / UI Programmer
Baut Editor-Tools, UI/UX, Asset-Pipelines und Dev-Utilities.

### World / Level Designer
Gestaltet Levels, platziert Assets, definiert Biome, erstellt Environment-Concepts.

### QA / Tester
Findet Bugs, validiert Features gegen Spezifikationen, sichert Release-Qualität.

### Technical Artist / VFX
Verantwortlich für Shader, Partikel-Effekte, Performance-Optimierung der Visuals.

### Blueprints
Unreal Engine's visuelles Scripting-System (Visual Scripting).

### C++
Die primäre Sprache für Performance-kritische Systeme in UE5.

### LLM
Large Language Model — Grundlage der KI-Systeme in AETHERIS.

### Agent-Orchestrierung
Die Koordination mehrerer autonomer Agenten (menschlich oder KI) für komplexe Tasks.
